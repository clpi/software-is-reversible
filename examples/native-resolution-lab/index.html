Exact chat and stopping

This is a deterministic contract chat with a finite, editable tensor. It does not call a language model. The engine computes exact score bounds and reports whether missing rows or a possible tie still prevent a canonical answer. Packed rows make the three explicit masses inspectable: m0 + 4·m1 + 16·mEOS, each mass 0–3. Use −1 for unknown.

Scope and proof boundary

This is a bounded native engine slice, not a native port of the entire campaign. HTML and a small JavaScript bridge carry physical input and DOM observations; planning, tensor decisions, and reversal gates are Idol. The Wasm modules are pinned and get no WASI authority. There is no JavaScript solver fallback and no external computer control.
