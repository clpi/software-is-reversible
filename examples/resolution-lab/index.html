    04 / AUDIT
    What the evidence supports
    

    Joint prerequisites and stopping
    Lean and exhaustive controls. A positive weighted score can miss Pareto points; a threshold can accept a candidate without certifying optimality.
    

    Append-only closure
    Canonical closure and worklist replay. On the seeded 512-hop chain, 514 registrations plus 512 waiter visits versus 659,206 cold rule checks (operation counts, not timings).
    

    Convergence, not invisible capture
    Named-cut convergence. Matching delivered facts gives matching views. Detecting missing source items requires a source checkpoint.
    

    Reversal and compression
    Scoped inversion proofs. The live controls above are synthetic. No global minimum encoding, verified external-system undo, or native speedup is asserted.
    

    Measured cost of keeping the certificate
    On two local Node runs, full five-axis cold median was 2.51–2.75 ms exhaustive, 2.27–2.50 ms factored, 2.31–2.71 ms factored with Idol Wasm comparisons. The narrowed control did not reliably get faster. Raw run 1 · Raw run 2.
    

    Native compiler and environment
    This preview runs the reference engine in your browser. Native Idol WASM requires its own build and equivalence receipt. No JavaScript fallback is reported as native.
